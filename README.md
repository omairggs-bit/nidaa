# نداء (Nidaa)

منصة عربية لبناء وصياغة أوامر الذكاء الاصطناعي (Prompts) بشكل احترافي، تدعم ChatGPT وClaude وGemini وGrok وCopilot وDeepSeek وMidjourney وFlux وVeo.

> نداء واحد، وإجابات من كل مكان.

## المزايا

- **مُنشئ أوامر بستّ خطوات**: الفكرة ← النموذج ← الجمهور ← اللغة ← الاحترافية ← الناتج، مع معاينة حية أثناء الكتابة.
- **مكتبة قوالب جاهزة** قابلة للبحث والتصفية حسب التصنيف (كتابة، برمجة، تصميم، تسويق، بحث، ترجمة، تلخيص، فيديو).
- **زر تحسين الأمر (✨)**: يضيف هيكلاً كاملاً (الدور، السياق، القيود، صيغة الإخراج، مثال).
- **السجل والمفضلة**: كل أمر تُنشئه يُحفظ محليًا، مع إمكانية إعادة تحميله أو نسخه أو حذفه.
- **تصدير** الأوامر بصيغة JSON أو TXT، ونسخ سريع بضغطة واحدة.
- **عداد كلمات ورموز** حي في كل من المُنشئ والمعاينة.
- **الوضع الليلي/النهاري** مع حفظ التفضيل.
- **اختصارات لوحة المفاتيح**:
  - `Ctrl/Cmd + K` — الانتقال إلى البحث في المكتبة.
  - `Ctrl/Cmd + Enter` — توليد الأمر مباشرة.
  - `Ctrl/Cmd + D` — تبديل المظهر.
- **خصوصية كاملة**: لا يوجد أي اتصال بخادم خارجي؛ كل البيانات (السجل، المفضلة، المظهر) تُخزَّن في `localStorage` الخاص بمتصفحك فقط.

## هيكل المشروع

```
nidaa/
├── index.html      # الهيكل والمحتوى
├── style.css       # نظام التصميم (بدون أي مكتبات خارجية)
├── app.js          # منطق التطبيق (JavaScript حديث، بدون تبعيات)
└── README.md
```

المشروع بالكامل ملفات ثابتة (Static) — لا يحتاج إلى خادم أو بناء (Build Step) أو أي حزم `npm`.

## التشغيل محليًا

افتح `index.html` مباشرة في المتصفح، أو استخدم أي خادم ثابت بسيط:

```bash
npx serve .
# أو
python3 -m http.server 5500
```

## النشر

المشروع جاهز للنشر مباشرة على:

- **GitHub Pages**: ادفع المجلد إلى فرع `main` وفعّل Pages من إعدادات المستودع.
- **Netlify**: اسحب المجلد إلى لوحة Netlify أو اربط المستودع مباشرة (لا حاجة لأمر بناء).
- **Vercel**: `vercel deploy` من داخل المجلد (Framework: Other / Static).

## التخصيص

- **الخطوط**: Reem Kufi (العناوين) · IBM Plex Sans Arabic (النصوص) · JetBrains Mono (الأرقام والبيانات) — محمّلة عبر Google Fonts في `index.html`.
- **الألوان**: معرّفة كمتغيرات CSS في أعلى `style.css` (`--brass`, `--echo`, وألوان الخلفية لكل من الوضعين الداكن والفاتح) لتسهيل تغيير الهوية البصرية من مكان واحد.
- **إضافة قوالب جديدة**: أضف كائنًا جديدًا إلى مصفوفة `TEMPLATES` في `app.js`.
- **إضافة نموذج ذكاء اصطناعي جديد**: أضف كائنًا جديدًا إلى مصفوفة `MODELS` في `app.js`، وعدّل دالة `buildPrompt` إذا احتاج النموذج أسلوب صياغة خاصًا (كما هو الحال مع نماذج الصور والفيديو).

## خارطة الطريق (مراحل لاحقة)

- تسجيل الدخول عبر Google وGitHub، وربط قاعدة بيانات لمزامنة السجل بين الأجهزة.
- مشاركة القوالب مع مجتمع نداء، مع تقييمات وتعليقات.
- تطبيق ويب تقدّمي (PWA) يعمل دون اتصال بالإنترنت.
- مساعد محادثة داخل الموقع لبناء الأوامر تفاعليًا.
